# Codex Instructions

Purpose: define Codex-specific working rules for this repository.

## Instruction Scope

- Follow direct user instructions and higher-priority system and developer instructions.
- The root `AGENTS.md` and agent-specific limit files are for mobile agents; do not read or follow them as Codex instructions.
- Use the README, project documentation, and source code for task-relevant technical context.
- Do not change mobile-agent instructions unless the user explicitly asks.

## Working Alongside Mobile Agents

- Treat their branches, commits, and local changes as the user's work.
- Inspect the current state before editing; preserve changes you did not make.
- If ownership or intent is unclear, ask before changing overlapping work.
